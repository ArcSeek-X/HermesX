### <a id="2-章节六前端主页面"></a>2. 章节六：前端主页面

状态持久化收口，`6.4 缓存集成` 重写为 `6.4 状态持久化与缓存`：

| 变更项 | 变更前 | 变更后 |
|--------|--------|--------|
| `pageState.kline` 结构 | 扁平 7 字段（`stockCode`/`stockName`/`period`/`stockInfo`/`klineData`/`prevClose`/`klineSource`） | `stockInfo` + `klineInfo` 两键（`klineInfo` 含 `period`/`klineData`/`klineSource`） |
| 行情数据类型 | 接口蛇形 `StockInfo`（`stock_code`/`current_price`…） | 领域类型 `StockQuoteCore`（`code`/`price`…），新增 `toStockSnapshot` 边界适配 |
| 股票代码 | 页面自写 `hrs-state-kline.stockCode`（session） | 由 `stockInfo.code` 派生，不再单独持久化 |
| 搜索框展示标签 | 页面自写 `hrs-state-kline.displayValue`（session） | 由 `stockInfo` + 本地索引重算，不落盘 |
| 周期 | `hrs-pref-kline.period`（localStorage，永久） | `klineInfo.period`（随 `pageState` 走 sessionStorage，会话级） |
| 存储键数量 | 4 处分散 | 仅 `hrs-state-pageState` 一个对象键 |

### <a id="3-已接受的取舍"></a>3. 已接受的取舍

| 取舍项 | 说明 |
|--------|------|
| 周期为会话级 | 关标签页后重置为 `daily`，不再永久记忆 |
| 加载失败不自动重试 | 上次加载失败时 `stockInfo` 为 `null`，刷新后股票代码为空，需手动重新搜索 |
| 跨页同步 | `StockDataViewPage` 读取同一切片复用数据，结构变更须同步该页 |

### <a id="7-新增章节六缓存集成"></a>7. 新增章节六：缓存集成

| 缓存项 | 层级 | 说明 |
|--------|------|------|
| 股票代码 | L2 + L3 (session) | 切换路由保持 + 刷新恢复 |
| 股票名称 | L3 (session) + 派生 | 输入框显示"名称（代码）"格式 |
| 默认周期 | L2 + L4 (local) | 跨路由保持 + 永久记住偏好 |
| 股票实时信息 | L1 (TTL=30s) | 价格实时性高 |
| K 线数据 | L1 (TTL=60s) | 日内数据中等缓存 |
