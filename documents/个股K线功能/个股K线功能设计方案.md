## 一、Context

"个股K线"查询功能，支持通过股票代码/名称/拼音/简拼搜索股票，查看多周期K线图（分时、日K、5日、周K、月K、年K、5/15/30/60/120分钟），并展示股票基本信息和技术指标（MA、MACD、成交量）。

搜索层面需求：

- 输入框显示"名称（代码）"格式（如"中科曙光（603019）"）
- 支持清除按钮快速重置搜索状态

风格和界面需求：

- 界面风格需与现有系统一致，保持统一性

**文件**：`api/v1/endpoints/kline.py`

### 2.1 A股行情周期数据标准定义对照表

> 说明：国内通达信、同花顺、东方财富等主流行情软件统一遵循下述统计规则；交易所无强制成文标准，但全市场行情服务商通用这套口径，可直接作为系统开发规范。

| 周期名称     | 标准专业定义         | 单根K线统计口径（开/高/低/收）                                        | 适用场景            | 重要开发备注                               |
| -------- | -------------- | -------------------------------------------------------- | --------------- | ------------------------------------ |
| **分时**   | 分时走势图（非K线蜡烛图）  | 以1分钟快照连续绘制价格曲线；展示单个交易日实时价格走势，附带均价线、昨收基准线；不生成K线Bar        | 日内交易、盘中实时盯盘     | 分时≠1分钟K线；无蜡烛形态；仅展示当日；午休11:30–13:00断档 |
| **日K**   | 日K线（日线）        | 1根K线=1个完整交易日；开盘：当日集合竞价开盘价；收盘：当日收盘价；最高/最低：全天价格极值          | 短线、波段核心分析周期     | 停牌、节假日无K线数据                          |
| **五日**   | 5日分时叠加图（多日分时）  | 叠加近5个交易日分时曲线，对比多日盘中走势，不属于K线周期                            | 短期盘口强弱对比        | 行业俗称，并非5日K线，不可与日线周期混淆                |
| **周K**   | 周K线（周线）        | 1根K线=完整交易周(周一至周五)；开盘：周一开盘价；收盘：周五收盘价；极值：全周所有交易日高低点        | 中期趋势判断，过滤单日波动杂波 | 短交易周仍取当周首个、最后一个交易日作为开收基准             |
| **月K**   | 月K线（月线）        | 1根K线=完整交易月；开盘：当月首个交易日开盘价；收盘：当月最后一日收盘价；极值：全月高低点           | 中长期趋势、大级别顶底研判   | 跨自然月停牌需特殊边界处理                        |
| **年K**   | 年K线（年线）        | 1根K线=完整自然交易年；开盘：当年首个交易日开盘价；收盘：年末最后一日收盘价；极值：全年价格区间        | 长线价值投资、年度级别周期分析 | 统计区间为每年1.1-12.31全部交易日                |
| **120分** | 120分钟K线（2小时K线） | 单根K线=连续120分钟交易；早盘09:30-11:30、下午13:00-15:00各生成1根          | 日内波段、超短线趋势分析    | A股天然适配，全天仅2根，不存在跨午休拼接                |
| **60分**  | 60分钟K线（小时线）    | 单根K线=连续60分钟交易切片，按09:30/10:30/11:30、13:00/14:00/15:00切割分段 | 日内短线、模拟T+0交易    | 午休断开，不合并上午尾盘与下午开盘数据                  |
| **30分**  | 30分钟K线         | 单根K线=连续30分钟交易切片生成标准K线Bar                                 | 短线日内买卖点位捕捉      | 短线交易高频使用周期                           |
| **15分**  | 15分钟K线         | 单根K线=连续15分钟交易切片生成标准K线Bar                                 | 超短线精细支撑压力判断     | 震荡行情精细化择时使用                          |
| **5分**   | 5分钟K线          | 单根K线=连续5分钟交易切片生成标准K线Bar                                  | 日内超短、盘口脉冲跟踪     | 数据噪音大，适合极精细日内分析                      |

| 序号 | 核心区分点      | 规范说明                                               |
| -- | ---------- | -------------------------------------------------- |
| 1  | 分时 vs 分钟K线 | 分时为折线面积图，无OHLC蜡烛数据；5/15/30/60/120分为离散蜡烛K线，两套独立渲染逻辑 |
| 2  | 五日周期误区     | 五日是多日分时叠加，不是5根日线合并的5日K线，接口与渲染完全独立                  |
| 3  | 分钟线午休规则    | 全部分钟周期禁止跨11:30-13:00午休拼接K线，午休自动截断分段                |

### 2.1.1补充说明：

- 分时图表展示标的**当日全部完整交易时段行情轨迹**，包含盘中已成交价格走势，直至当日收盘节点终止展示，无盘后 / 次交易日延伸数据。
- **假如：当前系统时间 13:45 ，图表完整展示 09:30–11:30和13:00-13:45 区间全部真实成交分时轨迹；13:45 至 15:00 尚未发生的交易无实际行情数据源，不预生成、不占位绘制空白 / 虚拟 K 线走势，但是需要留出未绘制的区域空间**

### 2.2 数据源优先级（三级降级）

| 优先级 | 数据源      | 适用周期        | 说明                        |
| --- | -------- | ----------- | ------------------------- |
| 1   | 东方财富 API | 日K/周K/月K/年K | 支持 beg=0 从上市开始拉取，分页获取全量数据 |
| 2   | 腾讯财经 API | 全部周期        | 分段日期拉取（每次2年），从最新往回拉取      |
| 3   | 新浪 API   | 分钟线         | datalen 限制为 1000（避免触发反爬）  |

### 2.3 东方财富分页拉取

```python
beg = "0"          # 从最早日期开始
end = "20500101"   # 到未来日期

# 循环请求，每次 1000 条
while 还有数据:
    请求 beg → end 的 1000 条
    去重并追加到结果集
    更新 beg = 最后一条日期 + 1 天
    如果返回不足 1000 条 → 已到最新日期，停止
```

- 单次请求 1000 条，最多 20 次（共 20000 条）
- 日K线 2000 条 ≈ 约 8 年数据，覆盖大多数股票上市以来的全部数据

### 2.6 接口参数

- `GET /api/v1/kline/search?q=xxx` — 股票搜索（代码/名称/拼音/简拼）
- `GET /api/v1/kline/{code}/kline?period=daily&limit=10000` — K线数据（limit 上限 10000）
- `GET /api/v1/kline/{code}/info` — 实时行情

### 2.7 分时数据特殊处理

**数据范围**：

- 分时（period=1m）只返回最新一个交易日的分钟数据
- 如果查询日不是交易日，则返回上一个交易日的完整分时数据

**新增返回字段**：

- `prev_close`：昨收价（用于前端计算涨跌幅百分比和绘制基准线）

**前端计算**：

- 涨跌幅百分比 = `(当前价 - 昨收价) / 昨收价 × 100%`
- 均价线 = `累计成交金额 / 累计成交量`

### 2.8 secid 映射规则

- 上海（6开头，含主板、科创板）：`1.{code}`
- 深圳（0/3开头，含主板、创业板）：`0.{code}`
- 北京（8/4开头，北交所）：`0.{code}`

### 2.9 klt 周期参数映射

- 分时(1m)→1, 5分钟→5, 15分钟→15, 30分钟→30, 60分钟→60, 120分钟→120
- 5日→101, 日K→101, 周K→102, 月K→103, 年K→104

### 4.1 网格布局

#### 4.1.1 分时模式（四行网格布局）

#### **分时图K线显示**说明：

- 分时图采用折线面积图渲染，无蜡烛图。
- **渲染方式**：折线面积图（蓝色渐变填充），不是蜡烛图。
- 分时图不需要缩放功能
- **均价线**：橙色线显示当天平均成交价（累计成交金额 / 累计成交量）
- **昨收价基准线**：水平虚线标记 0.00% 位置
- **交易时段标记**：11:30/13:00 午休分界线，在K线图上，有且只有一条午休分界线
- 分时图表展示标的**当日全部完整交易时段行情轨迹**，包含盘中已成交价格走势，直至当日收盘节点终止展示，无盘后 / 次交易日延伸数据。**假如：当前系统时间 13:45 ，图表完整展示 09:30–11:30和13:00-13:45 区间全部真实成交分时轨迹；13:45 至 15:00 尚未发生的交易无实际行情数据源，不预生成、不占位绘制空白 / 虚拟 K 线走势，但是需要留出未绘制的区域空间。**
- **在绘制分时图的走势图时候，图形上，09:30–11:30和13:00-13:45的区间段需要连续，不要断掉。**

### 4.2 时间轴刻度（按周期自适应）

参考主流股票软件（同花顺/东方财富）的时间轴显示逻辑：**标签数量固定约 5-6 个，均匀分布在整个时间轴上，始终显示完整日期**。

#### 4.2.1 参考图分析

| 周期       | 参考图标签示例                                                                       | 格式                    | 数量   | 分布              |
| -------- | ----------------------------------------------------------------------------- | --------------------- | ---- | --------------- |

| **月K**   | `2018-10-31` `2020-06-30` `2022-02-28` `2023-10-31` `2025-06-30`              | `YYYY-MM-DD`          | \~5个 | 均匀分布，约每1.5-2年一个 |
| **120分** | `2026-03-27 11:30:00` `2026-05-26 11:30:00` `2026-07-20 11:30:00`             | `YYYY-MM-DD HH:mm:ss` | \~3个 | 均匀分布，约每2个月一个    |

#### 4.2.2 核心设计原则

1. **标签数量固定**：始终显示约 5-6 个标签（小屏幕 3-4 个），不随数据量变化
2. **均匀分布**：标签在整个时间轴上均匀分布，不是按"每月第一个"规则
3. **完整日期**：始终显示 `YYYY-MM-DD`（日K/周K/月K/年K）或 `YYYY-MM-DD HH:mm`（分钟线）
4. **ECharts 自动均分**：利用 ECharts 的 `interval` 函数，按数据索引等间距选取标签

#### 4.2.4.1 缩放后刻度自适应（dataZoom 联动）

当用户通过底部滑块（dataZoom）放大 K 线图后，可见范围内的数据点减少，时间轴刻度应自动变密，**每个烛图下方都有对应的刻度标签**，方便用户精确查看每根 K 线的时间。

| 缩放状态          | 可见数据点数           | 刻度策略                  | 效果        |
| ------------- | ---------------- | --------------------- | --------- |
| **全量显示**（未缩放） | 全部数据             | 等间距 5-6 个标签           | 概览时间跨度    |
| **轻度缩放**      | 50\~200 根        | 每 N 根显示一个（N = 可见数/10） | 中等密度      |
| **深度缩放**      | ≤30 根（小屏幕 ≤20 根） | **每根烛图都显示刻度**         | 一一对应，精确查看 |

**实现逻辑**：

1. 监听 ECharts `dataZoom` 事件，获取当前可见范围 `{ start, end }`
2. 计算可见数据点数 `visibleCount = total * (end - start) / 100`
3. 当 `visibleCount ≤ 阈值` 时，`interval` 返回 `true`（显示所有标签）
4. 当 `visibleCount > 阈值` 时，使用预计算的等间距标签索引

```
阈值：小屏幕(<1000px) = 20，大屏幕 = 30
```

#### 4.2.5 实现方案

```typescript
/**
 * 根据周期类型计算时间轴标签索引和格式化函数
 *
 * 核心逻辑：等间距选取约 5-6 个标签（小屏幕 3-4 个），均匀分布在整个时间轴上
 *
 * @param data - K 线数据
 * @param period - 当前周期
 * @param isSmallScreen - 是否小屏幕（<1000px）
 * @returns { labelIndices: Set<number>, formatter: (value: string) => string }
 */
function computeTimeAxisLabels(
  data: KLinePoint[],
  period: KLinePeriod,
  isSmallScreen: boolean,
): { labelIndices: Set<number>; formatter: (value: string) => string } {
  const total = data.length;
  // 标签数量：大屏幕 5-6 个，小屏幕 3-4 个
  const labelCount = isSmallScreen ? 4 : 6;
  const step = Math.max(1, Math.floor(total / labelCount));

  // 等间距选取标签索引
  const labelIndices = new Set<number>();
  for (let i = 0; i < total; i += step) {
    labelIndices.add(i);
  }
  // 确保最后一个数据点也有标签
  if (total > 0) labelIndices.add(total - 1);

  // 判断是否为分钟线（含时间部分）
  const isIntraday = ['1m', '5m', '15m', '30m', '60m', '120m'].includes(period);
  // 判断是否为5日周期（5日周期属于日线级别，不含时间部分）
  const is5D = period === '5d';

  const formatter = (value: string): string => {
    if (period === '1m') {
      // 分时：只显示时间 HH:mm
      const timePart = value.split(' ')[1];
      if (!timePart) return value;
      const [h, m] = timePart.split(':');
      return `${h}:${m}`;
    }

    if (isIntraday) {
      // 分钟线（5m~120m）
      const parts = value.split(' ');
      const datePart = parts[0] || ''; // "2026-07-31"
      const timePart = parts[1] || ''; // "09:35:00"

      if (period === '120m') {
        // 120分钟：显示完整日期+时间 YYYY-MM-DD HH:mm
        return `${datePart} ${timePart.slice(0, 5)}`;
      }

      // 其他分钟线：小屏幕省略时间，只显示 MM-DD
      if (isSmallScreen) {
        return datePart.slice(5); // "07-31"
      }
      // 大屏幕：显示 MM-DD HH:mm
      return `${datePart.slice(5)} ${timePart.slice(0, 5)}`; // "07-31 09:35"
    }

    // 日K/周K/月K/年K：始终显示完整日期 YYYY-MM-DD
    return value; // "2025-07-28"
  };

  return { labelIndices, formatter };
}
```

#### **分时图Y轴**显示说明：

- **双 Y 轴**：左侧绝对价格，右侧涨跌幅百分比（以昨收价为基准 0.00%）

- **Y轴刻度优化**：使用 "Nice Number" 算法，将偏差向上取整到干净的数值（如 1、2、5、10 的倍数），确保刻度间隔均匀美观。目标7个刻度（0轴 + 上下各3个），间隔一致

- **最大值/最小值标记**：左侧Y轴顶部显示 `最高 XX.XX`（红色），底部显示 `最低 XX.XX`（绿色）；右侧Y轴顶部显示 `+X.XX%`（红色），底部显示 `-X.XX%`（绿色）
