# A股行情周期标准定义对照表
> 说明：国内通达信、同花顺、东方财富等主流行情软件统一遵循下述统计规则；交易所无强制成文标准，但全市场行情服务商通用这套口径，可直接作为系统开发规范。

| 周期名称 | 标准专业定义 | 单根K线统计口径（开/高/低/收） | 适用场景 | 重要开发备注 |
| ---- | ---- | ---- | ---- | ---- |
| **分时** | 分时走势图（非K线蜡烛图） | 以1分钟快照连续绘制价格曲线；展示单个交易日实时价格走势，附带均价线、昨收基准线；不生成K线Bar | 日内交易、盘中实时盯盘 | 分时≠1分钟K线；无蜡烛形态；仅展示当日；午休11:30–13:00断档 |
| **五日** | 5日分时叠加图（多日分时） | 叠加近5个交易日分时曲线，对比多日盘中走势，不属于K线周期 | 短期盘口强弱对比 | 行业俗称，并非5日K线，不可与日线周期混淆 |
| **日K** | 日K线（日线） | 1根K线=1个完整交易日；开盘：当日集合竞价开盘价；收盘：当日收盘价；最高/最低：全天价格极值 | 短线、波段核心分析周期 | 停牌、节假日无K线数据 |
| **周K** | 周K线（周线） | 1根K线=完整交易周(周一至周五)；开盘：周一开盘价；收盘：周五收盘价；极值：全周所有交易日高低点 | 中期趋势判断，过滤单日波动杂波 | 短交易周仍取当周首个、最后一个交易日作为开收基准 |
| **月K** | 月K线（月线） | 1根K线=完整交易月；开盘：当月首个交易日开盘价；收盘：当月最后一日收盘价；极值：全月高低点 | 中长期趋势、大级别顶底研判 | 跨自然月停牌需特殊边界处理 |
| **年K** | 年K线（年线） | 1根K线=完整自然交易年；开盘：当年首个交易日开盘价；收盘：年末最后一日收盘价；极值：全年价格区间 | 长线价值投资、年度级别周期分析 | 统计区间为每年1.1-12.31全部交易日 |
| **120分** | 120分钟K线（2小时K线） | 单根K线=连续120分钟交易；早盘09:30-11:30、下午13:00-15:00各生成1根 | 日内波段、超短线趋势分析 | A股天然适配，全天仅2根，不存在跨午休拼接 |
| **60分** | 60分钟K线（小时线） | 单根K线=连续60分钟交易切片，按09:30/10:30/11:30、13:00/14:00/15:00切割分段 | 日内短线、模拟T+0交易 | 午休断开，不合并上午尾盘与下午开盘数据 |
| **30分** | 30分钟K线 | 单根K线=连续30分钟交易切片生成标准K线Bar | 短线日内买卖点位捕捉 | 短线交易高频使用周期 |
| **15分** | 15分钟K线 | 单根K线=连续15分钟交易切片生成标准K线Bar | 超短线精细支撑压力判断 | 震荡行情精细化择时使用 |
| **5分** | 5分钟K线 | 单根K线=连续5分钟交易切片生成标准K线Bar | 日内超短、盘口脉冲跟踪 | 数据噪音大，适合极精细日内分析 |

| ---- | ---- | ---- |
| 1 | 分时 vs 分钟K线 | 分时为折线面积图，无OHLC蜡烛数据；5/15/30/60/120分为离散蜡烛K线，两套独立渲染逻辑 |
| 2 | 五日周期误区 | 五日是多日分时叠加，不是5根日线合并的5日K线，接口与渲染完全独立 |
