# 板块资金流向图 — 实现方案

> 基于东方财富日线资金流接口（klt=101），在 SectorAnalysisPage「板块资金 → A」tab 中实现多板块多日资金流折线图。横轴为日期，纵轴为主力净流入（亿，保留 2 位小数）。支持板块多选筛选、时间轴滑块、高区分度折线配色。

---

## 一、数据流与接口契约

### 1.1 后端新增端点

**文件**：`api/v1/endpoints/sector.py`（新增路由）

**端点**：`GET /api/v1/sector/fund-flow-history`

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `sector_type` | str | 否 | `industry`（默认）/ `concept` |
| `limit` | int | 否 | 返回天数，默认 30，最大 100 |
| `top_n` | int | 否 | 只返回资金流排名前 N 的板块，默认 10 |
| `sector_codes` | str | 否 | 指定板块代码，逗号分隔，如 `BK0475,BK0717` |

**返回结构**：

```json
{
  "dates": ["2026-07-28", "2026-07-29", "..."],
  "sectors": [
    {
      "code": "BK0475",
      "name": "银行",
      "series": [15.27, -18.74, "..."],
      "latest": 1.93,
      "color": "#e74c3c"
    }
  ]
}
```

**后端逻辑**：

1. 若指定 `sector_codes`，按指定代码获取板块；否则调用 `push2delay.eastmoney.com/api/qt/clist/get`（`m:90+t:2` 行业 / `m:90+t:3` 概念）获取板块列表，按 `f62`（主力净流入）降序取 TOP N
2. 对每个板块，调用 `push2his.eastmoney.com/api/qt/stock/fflow/kline/get`（`secid=90.{BK代码}`，`klt=101`，`lmt=limit`）
3. 解析返回的 `klines` 数组（格式：`日期,主力,小单,中单,大单,超大单`，单位元）
4. 主力净流入 ÷ 1e8 转为亿，保留 2 位小数
5. 按日期对齐各板块序列（缺失日期填 `None`）
6. 折线配色使用高区分度色板（蓝、绿、黄、红、青等），按板块顺序依次分配
7. 带重试（3 次，间隔 1.5s）应对 push2his 网络抖动；请求时显式设置 `proxies={"http": None, "https": None}` 绕过本地代理

**新增端点**：`GET /api/v1/sector/fund-flow-sectors`

返回指定类型的所有板块代码和名称列表，用于前端多选下拉框。

### 1.2 前端 API 层

**文件**：`apps/hrs-web/src/api/sectorData.ts`（新增函数）

```typescript
export type SectorFundFlowSeries = {
  code: string;
  name: string;
  series: (number | null)[];
  latest: number | null;
  color: string;
};

export type SectorFundFlowResponse = {
  dates: string[];
  sectors: SectorFundFlowSeries[];
};

export function fetchSectorFundFlowHistory(params?: {
  sectorType?: 'industry' | 'concept';
  limit?: number;
  topN?: number;
}): Promise<SectorFundFlowResponse> {
  return apiClient.get('/api/v1/sector/fund-flow-history', { params }).then(r => r.data);
}
```

**新增状态与加载逻辑**（在组件顶部）：

```typescript
const [fundSectorType, setFundSectorType] = useState<'industry' | 'concept'>('industry');
const [fundDays, setFundDays] = useState(30);
const [fundFlowData, setFundFlowData] = useState<SectorFundFlowResponse>({ dates: [], sectors: [] });
const [fundFlowLoading, setFundFlowLoading] = useState(false);
const [fundFlowError, setFundFlowError] = useState<string | null>(null);

const loadFundFlow = useCallback(async () => {
  setFundFlowLoading(true);
  setFundFlowError(null);
  try {
    const data = await fetchSectorFundFlowHistory({
      sectorType: fundSectorType,
      limit: fundDays,
      topN: 10,
    });
    setFundFlowData(data);
  } catch (e) {
    setFundFlowError(e instanceof Error ? e.message : '加载失败');
  } finally {
    setFundFlowLoading(false);
  }
}, [fundSectorType, fundDays]);

useEffect(() => { loadFundFlow(); }, [loadFundFlow]);
```

## 二、数字格式化规范

**统一使用项目现有方法**：

| 场景 | 方法 | 来源 |
|---|---|---|
| 元→亿（2位小数） | `(value / 1e8).toFixed(2)` | `KLineChart.tsx` 的 `formatAmount` |
| 带符号百分数 | `${value > 0 ? '+' : ''}${value.toFixed(2)}%` | `SectorTreemap.tsx` 的 `formatPercent` |
| null/NaN 兜底 | `'--'` | `SectorStockTable.tsx` 的 `safeNumber` |
| Y 轴刻度 | `v.toFixed(2)` | 与项目其他图表一致 |

**后端转换**（Python）：

```python
def _yuan_to_yi(value: float | None) -> float | None:
    if value is None:
        return None
    return round(value / 1e8, 2)
```

## 六、已知限制

- **数据粒度**：日线（无法实现盘中半小时曲线，东财公开接口不提供板块分钟级资金流历史）
- **数据源稳定性**：push2his 域名存在间歇性网络抖动，已通过重试机制缓解
- **板块数量**：默认 TOP 10，避免折线过多影响可读性；可通过 `top_n` 参数调整
