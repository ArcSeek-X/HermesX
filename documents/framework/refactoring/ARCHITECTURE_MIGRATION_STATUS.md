## 仍需处理

1. **本机 Docker 标签解析网络（环境项）**：本轮完整镜像和容器已通过；常规标签解析仍可能受本机镜像加速地址 403/直连 EOF 影响。本轮采用本地官方 OCI 输入完成验证，未改全局设置；不再列 Pro CSS 授权为当前构建阻塞。
2. **桌面端口与就绪判定**：本机已有 Python 监听 `*:8000`，Electron 仍选中 8000 并把其健康响应当作自带后端就绪，后者报 `FastAPI port is not available`。需单独收敛端口选择和后端身份 / 启动失败判定，禁止停止维护者已有服务来制造通过；该问题尚未修复，2026-11-06 已用隔离用户目录复现。此次冻结后端已使用空闲端口独立验证成功，但不能代替 Electron 窗口验收；未复制到 /Applications、未改系统 Gatekeeper、未使用 Apple Developer 身份或公证；Windows / Intel 安装与运行尚未验收。
3. **UI 治理规则**：禁止原生 title 的既有守卫与维护者保留当前提示方式的决定不一致，仍待独立调整，不通过引入 Tooltip 修改页面来满足它。
4. **服务端大文件后续演进**：本轮第二轮职责拆分已落地，原 13 件处理决定及保留理由见专项交接；不再把所有 ≥1800 行文件笼统列为未完成。
5. **data_provider 专项余项与既有门禁失败**：B00–B22 和矩阵已收口；B23 外部验收缺口保留。静态 API 描述失败已修正，历史热点并发偶发超时仍保留待查，不以本轮未重现代替根因调查。
6. **前端全量 lint**：按维护者决定最后处理，本轮未重跑，不沿用旧数字充当当前实测结果。
