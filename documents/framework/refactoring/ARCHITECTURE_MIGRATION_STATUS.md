## 仍需处理

1. **Docker 授权**：维护者已确认保留 `@heroui-pro/react/css`。需按现有 Pro 授权方式提供干净构建所需样式，再重跑标准 Dockerfile 的完整镜像构建和容器启动。不要删除依赖或更改页面来绕过授权。此前 Aliyun 镜像代理 403、apt 瞬时 502 属环境问题；本轮通过临时 Dockerfile 显式引用相同官方基础镜像继续诊断，未改全局镜像源，未获得最终应用镜像。
2. **桌面端口与就绪判定**：本机已有 Python 监听 `*:8000`，Electron 仍选中 8000 并把其健康响应当作自带后端就绪，后者报 `FastAPI port is not available`。需单独收敛端口选择和后端身份 / 启动失败判定，禁止停止维护者已有服务来制造通过；该问题尚未修复。本轮未复制到 /Applications、未改系统 Gatekeeper、未使用 Apple Developer 身份或公证；Windows / Intel 安装与运行尚未验收。
3. **UI 治理规则**：禁止原生 title 的既有守卫与维护者保留当前提示方式的决定不一致，仍待独立调整，不通过引入 Tooltip 修改页面来满足它。
4. **服务端大文件后续演进**：本轮第二轮职责拆分已落地，原 13 件处理决定及保留理由见专项交接；不再把所有 ≥1800 行文件笼统列为未完成。
5. **前端全量 lint**：按维护者决定最后处理，本轮未重跑，不沿用旧数字充当当前实测结果。
