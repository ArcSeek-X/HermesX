## 实施过程中发现并修复的问题

| 序号 | 问题描述 | 影响范围 | 修复方案 | 修复日期 |
|------|---------|---------|---------|---------|
| 1 | `useCachedState` 未将 `null` 视为无值，导致输入框显示 "null" | useCachedState.ts | 增加 `nested !== null` 判断 | 2026-08-01 |
| 2 | `onClear` 中 `setStockCode('')` 和 `setPageState({ stockCode: null })` 冲突 | StockKLinePage.tsx | 统一使用空字符串 `''` | 2026-08-01 |
| 3 | `displayValue` 条件只检查 `stockName`，未检查 `stockCode` | StockKLinePage.tsx | 改为 `stockCode && stockName` | 2026-08-01 |
| 4 | ECharts 时间轴刻度 `interval` 函数使用闭包 Set，滑块移动后刻度消失 | KLineChart.tsx | 预计算 `monthLabelIndices` Set | 2026-08-01 |
| 5 | 新浪 API `datalen` 超过 1000 触发反爬返回 null | kline.py | 限制 `sina_limit = min(limit, 1000)` | 2026-08-01 |
| 6 | 中文股票名称搜索失败（本地索引不含中文名） | StockKLinePage.tsx | 添加后端 `searchStocks` API 解析 | 2026-08-01 |
