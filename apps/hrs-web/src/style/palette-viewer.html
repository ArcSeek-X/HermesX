palette.css × HeroUI 同名参数比对

本项目 index.css 与 palette.css 中的同名变量（如 --background、--border、--danger 等） 位于 @layer 之外（unlayered），优先级恒高于 HeroUI 的 theme layer，因此会单向覆盖 HeroUI 的同名变量。 右侧「HeroUI 参数」列出 HeroUI v3 默认主题在当前主题下的取值（来自其 published 主题变量），用于显性比对本项目覆盖后可能造成的色差 / 失效。 HeroUI 值为其默认主题实际声明，深色取值取自其 GitHub 仓库 themes/default/variables.css。

说明：HeroUI 使用 oklch / 自包含颜色（如 oklch(0.97 0.005 255)），其颜色块由浏览器直接解析渲染； 本项目的同名变量为 HSL 分量（193 100% 43%），已自动补 hsl() 后渲染。 两者格式不同但都显示为实色，便于直接对照覆盖前后的视觉差异。
