- **更正（上面第 11 条有误，以下为准）**：HeroUI v3 的下拉**滚动容器是弹层本身**——`@heroui/styles/dist/components/select.css` 里 `.select__popover` 自带 `overflow-y-auto`，而 `[data-slot="list-box"]` 只有 `p-1.5`、自身**不可滚动**。给 list-box 加 `max-h-*` 只会把它裁断且滚不动；正确做法是**只限高弹层**。另外 react-aria 的 `Popover` 会按视口/placement 注入 inline `max-height`（如 623px），压过 class 上的 `max-h-[400px]`，必须用 Tailwind v4 的 `!` 后缀（`max-h-[400px]!`）提权才能生效。最终：`popoverClassName="countrySelectPopover max-h-[400px]! overflow-y-auto"`。注意这与 COMPONENTS.md「禁止 !important」冲突，属压制第三方内联样式的例外。
