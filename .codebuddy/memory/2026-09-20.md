## 删除 routeMeta.ts（改用 useMatches + handle）
- `router/routeMeta.ts`（`ROUTE_META: routePath→{title,description}` 索引，供 ShellHeader 查页头）**判定为冗余**：其数据（path/title=menuName/description=menuDescription）已被 `asyncRouterData`（routerPath/routerName/routerDescription）完全覆盖，且每个 `<Route>` 已挂 `handle`。
- 替代方案：删除 routeMeta.ts；`AppContent.buildRoute` 的 `handle` 扩展为 `{ menuName, menuId, description, icon }`（description 取 routerDescription，menuId 取 routerKey）；`ShellHeader` 改用 `useMatches()` 取 `matches[last].handle` 推导页头标题/描述，移除了 `useLocation` 与 `ROUTE_META` 依赖。
- 注意：AppContent 中 `if (true){ alert(location.pathname) }` 是用户调试代码（注释残片 `authEnabled && !loggedI` 显示原应 `if(authEnabled && !loggedIn)`），会触发 authEnabled/loggedIn 未使用 + no-constant-condition 错误，非本次改动；ShellHeader 中 `<StockSearch>` 传 `placeholder`/`ariaLabel` 但 `StockSearchProps` 已无此二字段（既有不匹配）。两处均非 routeMeta 重构引入，未擅自修改。
