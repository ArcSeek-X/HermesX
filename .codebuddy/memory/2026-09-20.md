## A 类测试文件修复（test-side only，未改生产组件）

用户要求处理之前审计中归为「A 类（label 未关联控件）」的 3 个测试文件。结论：

- **AlertRuleForm.test.tsx（18 用例）** + **AlertRuleList.test.tsx（9 用例）**：确属 label 未关联。表单字段均为 `<div><label>文案</label><Input/Select/Checkbox></div>`，label 无 `htmlFor`。`getByLabelText` 取不到。
  - 修复：测试侧加 `field(labelText)` helper —— `screen.getByText(label, { selector: 'label' }).parentElement.querySelector('input, select, textarea')`。
  - 关键坑：`RSI 阈值` 标签与「规则类型」下拉里的 `rsi_threshold` **选项文案**同为 `RSI 阈值`，`getByText` 会命中两个 → 必须加 `selector: 'label'` 限定只选 label 元素。
  - `JP/KR shows` 用例是**过时断言**：组件 `ALERT_MARKET_REGION_OPTIONS` 现在只有 cn/hk/us，没有 jp/kr → 改为断言 jp/kr 不存在。
- **StockSearch.test.tsx（22 用例）**：其实**不是 A 类，是 C 类（过时断言）**。组件已重构：
  - `placeholder` / `ariaLabel` prop 不再生效，占位符与 aria-label 均取自 i18n（zh: `输入股票代码或名称`，en: `Enter a stock code or name`）。
  - 已无 `data-autocomplete-mode` 降级输入框；运行时异常由 `StockSearchBoundary` 直接 `return null`（卸载整个搜索框）。
  - 建议展开时回车提交的是**首个候选**（`600519.SH` 等），而非原文。
  - `StockSearchList` 的 `MarketBadge` 对不支持市场（如 `OTC`）直接 `throw` → 被 ErrorBoundary 捕获 → 搜索框整体卸载。
  - 修复：断言改为当前真实行为（i18n placeholder、aria-label、首个候选提交、异常时 combobox 不存在、OTC 时优雅降级卸载+上报 console.error）。OTC 用例需 `fireEvent.focus(input)` 触发下拉渲染（下拉 `dropdownStyle` 在 rAF 里设置）才能复现抛错路径。
