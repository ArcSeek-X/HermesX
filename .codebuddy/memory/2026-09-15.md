## 主题架构评估（ThemeSync 是否需要，用户询问）
- 结论：ThemeSync 必须保留。（1）它是 themeColor 写 --primary 的**唯一已提交/加载落地点**（applyPrimaryColor 为纯 DOM 函数，全项目仅 ThemeSync 与 ThemeSetting 预览期调用）；（2）做 store->next-themes 单向同步（setTheme(themeMode) 触发 html class 与 resolvedTheme）。
- 架构瑕疵（待收敛）：主题有**两套并行控制器**——ThemeSetting 走 themeStore，ThemeToggle 却直接 next-themes.setTheme 绕过 store，导致 themeStore.themeMode 与 next-themes 实际值会分叉（store 失真）。ThemeSync 仅单向同步、无反向。建议让 ThemeToggle 也走 setThemeMode，或 ThemeSync 加 next-themes->store 反向订阅，使 store 成为唯一真值。另 syncNextThemesTheme 与 ThemeSync.setTheme 重复写 localStorage.theme（冗余）。

## ThemeSetting 预览主题切换时间差（过渡不一致）分析与修复
- 现象：预览切主题色时菜单图标瞬变、文字延迟；切主题模式时图标与文字都延迟（视觉时间差）。
- 根因（代码实现问题 + CSS 过渡）：提交路径（保存→setThemeMode→ThemeSync→next-themes setTheme）会触发 `ThemeProvider` 的 `disableTransitionOnChange`（已开），next-themes 临时注入 `*{transition:none}` 抑制过渡→一致瞬变。而预览路径（`applyModePreview`/`applyPrimaryColor` 直接操作 DOM，上一轮为避免打断 TabNav 指示条滑动而改）**绕过 next-themes**，`disableTransitionOnChange` 不触发，全站 100+ 处 `transition:color/background` 照常运行→时间差。不一致来源：不同元素过渡配置不同（图标走无过渡 fill/currentColor、文字带 transition:color）。
- 修复：在 `applyPreview` 应用前注入全局 `*{transition:none!important;animation:none!important}` 的 `<style>`，但用更高优先级 `[data-slot="tabs-indicator"]{transition:transform 200ms ease!important}` 单独保留指示条滑动；强制重排后改 `--primary`/class，下一帧 `requestAnimationFrame` 移除该 style。用模块级单例 `noTransitionStyle` 避免重复节点。预览与提交在"切换瞬间一致瞬变"上对齐，指示条动画不丢。
- 经验：预览走直接 DOM 旁路 next-themes 时，必须自行复刻 `disableTransitionOnChange` 的过渡抑制，否则会与提交路径表现不一致。

## ThemeSetting 模式预览失效修复
- 根因：`TabNav` 的 `onChange` 把 `applyPreview` 包在 `requestAnimationFrame` 里、且模式预览走 next-themes `setTheme`（重渲染 ThemeProvider），导致模式预览不生效；颜色预览因 `applyPrimaryColor` 直接写 `--primary` 是同步的，所以生效。
- 修法：新增模块级 `applyModePreview(mode)` 直接切换 `<html>` 的 light/dark class（system 按 matchMedia 解析），`applyPreview` 改为 `applyModePreview(m)+applyPrimaryColor(c)`，`onChange` 同步调用、去掉 rAF；移除 ThemeSetting 里不再用的 `next-themes useTheme/setTheme`。
- 效果：模式预览即时生效（与颜色一致），且因不再重渲染 ThemeProvider，**反而保住了 TabNav 指示条滑动动画**（原 rAF 想绕开的问题从根上消除）。预览只动 DOM 不碰 store/localStorage，保存仍经 `setThemeMode`→ThemeSync→next-themes 提交。
